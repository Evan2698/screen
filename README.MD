# Screen

一个面向 Android 设备的远程屏幕投屏项目，适用于 Tesla 车机浏览器等场景。通过热点连接后，可在车机中实时查看手机屏幕内容，并进行点击、滑动和按键控制。

本项目使用 WebSocket + JPEG 图像流方案，不依赖 WebRTC 和 MJPEG，适合低带宽、低延迟的车载环境。已在 Tesla Model Y 2023 - 2025 上完成功能验证。

## 项目概览

- Android 端实时截屏
- 低延迟图像推送
- 车机浏览器可直接访问
- 无障碍服务支持触屏和按键控制
- 适配 Android 14 及以上系统

## 功能特性

- 使用 MediaProjection 采集屏幕内容
- 将帧数据压缩为 JPEG 并通过 WebSocket 发送
- 在浏览器端使用 Canvas 进行显示
- 可将浏览器点击/拖动/按键操作转发回 Android
- 通过前台服务保持投屏持续工作
- 支持通过热点方式进行车载远程访问

## 使用场景

- 车载屏幕展示
- 手机屏幕远程查看
- 特斯拉浏览器投屏控制
- 低带宽环境下的轻量图像传输

## 运行要求

- Android 14 及以上
- 手机支持热点功能
- Tesla 车机可以连接手机热点
- 允许以下权限：
  - 屏幕录制权限
  - 前台服务权限
  - 辅助功能服务权限

## 快速开始

### 1. 打开手机热点

启动手机热点，并确保热点网络稳定可用。

### 2. 让 Tesla 连接热点

在车机中连接该热点，并勾选“在行驶中保持网络连接”等相关选项，确保车机不会在驾驶状态下断网。

### 3. 启动应用

- 打开本应用
- 授权屏幕录制权限
- 若系统提示开启辅助功能服务，请进入系统设置并开启本应用的无障碍权限
- 启动投屏服务

### 4. 访问投屏地址

在车机浏览器中打开：

http://9.9.9.9:8080

如果实际地址不同，请以应用内显示的服务地址为准。

### 5. 连接并使用

在页面中点击 Connect 按钮即可开始投屏。页面支持基本的点击、拖动和按键事件。

## 技术实现

核心模块说明：

- ScreenCaptureService：负责屏幕捕获、前台服务、Web 服务器管理和图像采集
- WebServer：提供 HTTP 与 WebSocket 服务
- TouchAccessibilityService：将浏览器端的输入事件转成 Android 触摸和按键操作
- MainActivity：应用主界面，负责控制服务开关和显示状态

数据流如下：

1. Android 通过 MediaProjection 获取屏幕帧
2. 帧数据被压缩为 JPEG 图像
3. 图像通过 WebSocket 实时推送到浏览器
4. 浏览器在 Canvas 中渲染显示
5. 前端交互事件回传至 Android
6. Accessibility Service 将事件转换为真实手势与按键操作

## 构建说明

### Android Studio

1. 打开项目
2. 等待 Gradle 同步完成
3. 选择目标设备
4. 运行应用

### 命令行

./gradlew assembleDebug

构建产物位于 app/build/outputs/apk/ 目录下。

## 注意事项

- 这是一个面向车载场景的定制化投屏方案，并非通用跨平台镜像工具
- 运行前请确保热点连接稳定且车机可访问目标地址
- 如页面无法连接，请检查：
  - 屏幕录制权限是否已授权
  - 无障碍服务是否已打开
  - 前台服务是否正常运行
  - 热点网络是否稳定
- 图像传输经过压缩，画质和帧率受网络状况影响
